# Core UI Font

Rajdhani is the selected core UI font. It is a royalty-free Google Font distributed under the SIL Open Font License, Version 1.1. The matching license text is stored in `Licenses`.

## Assets

- `Source/Rajdhani-SemiBold.ttf`: source font file.
- `TMP/Rajdhani SDF.asset`: TextMesh Pro font asset.
- `TMP/Materials/Rajdhani NeonGlow.mat`: glow preset for display/HUD text.

Run `Orbital Escape/UI/Apply Rajdhani To Current UI Prefabs` to apply the selected font to current UI prefabs.
