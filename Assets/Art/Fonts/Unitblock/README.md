# Core UI Font

Unitblock is the selected core UI font.

## Assets

- `Unitblock.ttf`: source font file.
- `Unitblock SDF.asset`: dynamic TextMesh Pro font asset using its generated default material.

Runtime palette colours are applied once per explicitly configured font material through `PaletteFontMaterialConfig`. Assign a separate Unitblock material to a text when it needs independent palette or merge settings.
